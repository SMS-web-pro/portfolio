## 🎨 Animations CSS Implémentées

### Animations de Base
- **fadeInUp** - Apparition progressive avec mouvement vertical
- **fadeInDown** - Apparition du haut vers le bas
- **slideInLeft** - Entrée depuis la gauche
- **slideInRight** - Entrée depuis la droite
- **scaleIn** - Agrandissement progressif

### Animations Avancées
- **pulse-scale** - Pulsation douce avec changement d'échelle
- **float** - Flottement vertical continu
- **float-delayed** - Flottement avec délai
- **rotate-slow** - Rotation lente et continue
- **blob-animation** - Animation de formes organiques (blobs)
- **gradient-shift** - Déplacement de dégradé
- **text-shimmer** - Effet de lueur sur le texte
- **slide-up-fade** - Glissement vers le haut avec fondu
- **rotate-x** - Rotation 3D sur l'axe X
- **bounce-delayed** - Rebond avec délai personnalisé

### Effets de Hover
- **hover:glow-effect** - Effet de lueur au survol
- **hover:lift** - Soulèvement avec ombre au survol
- **group-hover:scale-105** - Agrandissement au survol du groupe

## 🎭 Composants Animés

- Ajoute de la classe entre les sections

- **Hook personnalisé** pour déclencher des animations au scroll
- Utilise l'Intersection Observer API
- Thresholds et margins configurables

## 🚀 Performance & Optimisation

### Techniques Utilisées
- CSS `animation` vs `transition` approprié à l'usage
- GPU-accelerated properties (transform, opacity)
- Delays configurables (animationDelay)
- Transitions smooth avec cubic-bezier personnalisés

### Responsive
- Animations adaptées au viewport
- Moins intense sur mobile (optionnel)
- Dégradés parfaits sur tous les écrans
